# 📈 Stock Portfolio Tracker — CodeAlpha Internship

## 📌 Project Overview
The Stock Portfolio Tracker is a Python application designed to record stock investments and calculate their total value using stock prices defined in the program.

Portfolio information is stored in a CSV file, allowing the application to work with structured data saved locally.

This project was completed as part of my **CodeAlpha Python Programming Internship**.

## 🎯 Objectives
- Practice Python programming.
- Understand file handling with CSV files.
- Perform calculations using stock prices and quantities.
- Organize and manage portfolio data.

## ✨ Features
- Tracks stock investments.
- Uses predefined stock prices.
- Calculates investment values based on stock quantities.
- Stores portfolio information in a CSV file.

## 🛠️ Technologies Used
- **Language:** Python 3
- **Data Storage:** CSV
- **Interface:** Command-line / Terminal

## ▶️ How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program:

   ```bash
   python stock_tracker.py
   ```
