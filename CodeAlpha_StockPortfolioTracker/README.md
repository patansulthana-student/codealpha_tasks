# CodeAlpha Stock Portfolio Tracker

## Project Description
A Python program that tracks stock investments, calculates portfolio values, and stores portfolio information in a CSV file.

## Features
- View available stock prices
- Add stocks and quantities to a portfolio
- Calculate the total portfolio value
- Store portfolio data in a CSV file

## Technologies Used
- Python
- CSV file handling

## How to Run
1. Install Python.
2. Open the terminal in this folder.
3. Run `python stock_tracker.py`.
