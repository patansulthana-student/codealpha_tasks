# 🎮 Hangman Game — CodeAlpha Internship

## 📌 Project Overview
The Hangman Game is a simple, interactive word-guessing game developed using Python. The player tries to guess a hidden word by entering letters one at a time.

This project was completed as part of my **CodeAlpha Python Programming Internship** to practice Python fundamentals and problem-solving skills.

## 🎯 Objectives
- Practice Python programming fundamentals.
- Understand conditional statements and loops.
- Work with strings and user input.
- Develop logical thinking through a simple game.

## ✨ Features
- Interactive gameplay through the terminal.
- Accepts letter guesses from the player.
- Provides feedback for guesses.
- Allows the player to continue guessing until the game ends.

## 🛠️ Technologies Used
- **Language:** Python 3
- **Interface:** Command-line / Terminal

## ▶️ How to Run
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   ```bash
   python hangman.py
   ```
