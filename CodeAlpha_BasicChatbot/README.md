# CodeAlpha Basic Chatbot

## Project Description
A simple rule-based chatbot developed using Python. It responds to basic messages such as "hello", "how are you", and "bye".

## Features
- Responds to greetings
- Replies to simple questions
- Ends the conversation when the user types "bye"
- Handles unknown messages

## Technologies Used
- Python

## How to Run
1. Install Python.
2. Open the terminal in this folder.
3. Run `python chatbot.py`.
