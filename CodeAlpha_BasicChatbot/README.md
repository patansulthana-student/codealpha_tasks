# 🤖 Basic Chatbot — CodeAlpha Internship

## 📌 Project Overview
The Basic Chatbot is a simple rule-based chatbot developed using Python. It accepts messages from the user and responds to predefined inputs such as greetings, simple questions, and goodbye messages.

The chatbot runs in the terminal and demonstrates how Python conditions can be used to create a basic conversation.

This project was completed as part of my **CodeAlpha Python Programming Internship**.

## 🎯 Objectives
- Understand user input and output in Python.
- Practice conditional statements.
- Use loops to maintain a conversation.
- Develop a simple rule-based response system.

## ✨ Features
- Responds to the message `hello`.
- Replies to `how are you`.
- Ends the conversation when the user types `bye`.
- Provides a default response for unrecognized messages.
- Accepts input in a case-insensitive manner and removes extra spaces.

## 🛠️ Technologies Used
- **Language:** Python 3
- **Interface:** Command-line / Terminal

## ▶️ How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program:

   ```bash
   python chatbot.py
   ```

## 💬 Sample Interaction
```text
===================================
       BASIC PYTHON CHATBOT
===================================
Hello! I am your chatbot.
You can say: hello, how are you, or bye.

You: hello
Bot: Hi!

You: how are you
Bot: I'm fine, thanks!

You: bye
Bot: Goodbye!
```
